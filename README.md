# Executive Fellowship in AI Law & Digital Sovereignty

An academic curriculum and research project focused on **technology legal practice in Uganda and East Africa**, covering cyber law, data protection, AI governance, and digital sovereignty with comparative perspectives from the EU, UK, US, Kenya, and South Africa.

## Overview

This repository contains a multi-week academic course with lectures, formative assessments, marked student work, and research papers. The curriculum is built around practical, problem-oriented learning — with particular emphasis on gaps in tech regulation in Ugandan

## Key Documents

- `latest AI law detail cirriculum.docx` — master curriculum document
- Module notes for computer systems, internet architecture, databases, APIs, cloud computing, and SDLC
- Formative assessments and marked student samples
- Research papers on the abstraction layer problem, digital sovereignty, and related topics

## AI Agent Framework (32 Agents)

The project uses **opencode** to define 32 specialised AI agents across 10 domains:

| Domain | Agents |
|---|---|
| **Writing** | Article, LinkedIn, book, and Substack drafting agents |
| **Teaching** | Curriculum, assessment, human assessor, AI identifier agents |
| **Policy** | Regulatory impact, policy drafting, legislative drafting agents |
| **Transactional** | Contract drafting, DPA, legal opinion agents |
| **Litigation** | Pleading, litigation, digital evidence, constitutional petition agents |
| **Compliance** | Privacy and cybersecurity compliance agents |
| **Governance** | DPIA, AI governance, AI audit agents |
| **Research** | Legal research, constitutional interpretation, comparative law, case digest agents |
| **Sovereignty** | Digital sovereignty agent |
| **Strategy** | Technology strategy and regulatory strategy agents |
